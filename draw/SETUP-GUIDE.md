# دليل تشغيل نظام القرعة اللايف (متعدد الأجهزة)

هاي الميزة الجديدة تخلي كل واحد يفتح الرابط من جهازه (موبايل/لابتوب) ويشوف القرعة **لايف أول بأول**، وبس أنت (الأدمن) تقدر تسحب وتحدد الفائزين. هاد يحتاج ربط بسيط ومجاني مع خدمة اسمها **Firebase** (من قوقل) عشان تزامن البيانات بين الأجهزة. خطوات مرة وحدة بس، وبعدها كل شي شغال تلقائي.

---

## الخطوة 1 — إنشاء مشروع Firebase مجاني (٣ دقائق)

1. روح على: https://console.firebase.google.com
2. سجل دخول بحساب Google عادي (ما بحتاج بطاقة ائتمان، الخطة المجانية كافية جدًا لهاي الفعالية).
3. اضغط **"Add project"** (أو "إنشاء مشروع").
4. أعطي المشروع اسم متل: `ieee-sports-draw-2026` واستمر بالخطوات (تقدر تعطل Google Analytics، مش لازم).
5. لما يخلص، بتوصل للوحة تحكم المشروع.

## الخطوة 2 — تفعيل Realtime Database

1. من القائمة الجانبية اليسار: **Build → Realtime Database**.
2. اضغط **Create Database**.
3. اختار أي منطقة قريبة (مثلاً `europe-west1` أو الافتراضي).
4. اختار **"Start in test mode"** ثم Enable.
   - ⚠️ **ملاحظة أمان بسيطة**: test mode معناها أي حد عنده رابط الـ API يقدر يكتب بيانات نظريًا. الحماية الحقيقية عندك هي إنه محدا غيرك يعرف **كلمة سر الأدمن** (اللي رح تحطها بالخطوة 4)، فحتى لو حدا وصل لقاعدة البيانات مباشرة ما رح يقدر يتحكم بالواجهة. هاد مستوى حماية كافي لفعالية قصيرة زي هاي. إذا بدك حماية أقوى (Firebase Auth كاملة)، خبرني وبساعدك تزودها.

## الخطوة 3 — إضافة تطبيق ويب وأخذ الإعدادات (Config)

1. من لوحة المشروع، اضغط أيقونة الترس ⚙️ (أعلى اليسار) → **Project settings**.
2. تحت "Your apps"، اضغط أيقونة **</>** (Web app).
3. أعطيه اسم مثل `draw-system` واضغط **Register app** (لا تحتاج Firebase Hosting، تجاهلها).
4. رح يطلع لك كائن كود اسمه `firebaseConfig` شكله متل هيك:

```js
const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "ieee-sports-draw-2026.firebaseapp.com",
  databaseURL: "https://ieee-sports-draw-2026-default-rtdb.firebaseio.com",
  projectId: "ieee-sports-draw-2026",
  storageBucket: "ieee-sports-draw-2026.appspot.com",
  messagingSenderId: "123456789",
  appId: "1:123456789:web:abcdef"
};
```

5. انسخ هاي القيم وحطها داخل ملف **`firebase-config.js`** المرفق (بدل القيم اللي فيها `PASTE_YOUR_...`).

## الخطوة 4 — تحديد كلمة سر الأدمن

بنفس ملف `firebase-config.js`، غيّر هاد السطر لكلمة سر من عندك:

```js
const ADMIN_PASSWORD = "ieee2026-change-me";
```

هاي الكلمة هي اللي رح تدخلها بس إنت من زر 🛡 بأعلى الصفحة عشان تفتح صلاحيات التحكم (السحب، تحديد الفائز، الـ Reset). أي حد يفتح الرابط بدون هاي الكلمة بضل بوضع "View Only" — بس يشوف، ما يقدر يغير إشي.

## الخطوة 5 — استضافة الملفات (Hosting)

لازم الملفات الأربعة (`index.html`, `style.css`, `script.js`, `firebase-config.js`) تكون كلها بنفس المجلد، ومرفوعة مكان يقدر الكل يوصله من موبايله. أسهل طريقتين مجانيتين:

**الخيار الأسهل — Netlify Drop:**
1. روح على https://app.netlify.com/drop
2. اسحب المجلد كامل (فيه الملفات الأربعة) وفلته بالصفحة.
3. رح تاخد رابط جاهز فورًا (مثال: `https://ieee-draw-2026.netlify.app`) — هاد الرابط شاركه مع الكل (اعمله QR Code لو حابب).

**أو GitHub Pages:** ارفع الملفات لمستودع GitHub وفعّل GitHub Pages من الإعدادات — بياخد وقت أطول شوي بس مجاني ودائم.

## الخطوة 6 — التشغيل يوم الفعالية

1. افتح الرابط من جهازك، اضغط 🛡 بأعلى يمين الصفحة، دخل كلمة سر الأدمن. الجهاز رح يفتكرها (ما رح يطلبها ثانية على نفس الجهاز/المتصفح).
2. شارك نفس الرابط مع الجمهور (QR Code أسهل وسيلة) — كل واحد يفتحه من جهازه ويشوف نفس القرعة أول بأول بدون ما يحتاج يعمل أي شي.
3. إنت بس اللي تختار الرياضة، تعمل السحب، وتحدد الفائزين — كل تغيير بينعكس فورًا عند كل الأجهزة المتصلة.

---

### إذا ما ضبطت `firebase-config.js`

النظام بيشتغل برضه محليًا على جهازك بس (بدون مزامنة لايف بين الأجهزة) — مفيد للتجربة والتدريب قبل الفعالية.
